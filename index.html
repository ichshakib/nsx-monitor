Product Overview

NSX Monitor is a lightweight network monitoring utility designed for developers, network engineers, and system power users. It provides sub-second byte tracking (Rx/Tx), interface throughput statistics, latency tracking, and an always-on-top desktop overlay widget.

Built for speed and low resource usage, all bandwidth metrics remain 100% private and stored locally on your machine with zero remote tracking.

Core Features
Feature Description
Real-Time Polling Sub-second tracking of incoming and outgoing bandwidth across all connected network adapters.
Desktop Overlay Widget Always-on-top compact mini-window for gaming, streaming, and programming.
Historical Usage Logs Query past traffic consumption over 1 hour, 24 hours, 7 days, and 30 days.
Bandwidth Alerts Set custom threshold limits with system notifications when bandwidth spikes.
Multi-Adapter Detection Automatically detect Ethernet, Wi-Fi, and virtual VPN adapters.
100% Local Privacy No telemetry sent to remote servers. All metric logs stay strictly on your local PC.
System Requirements
Supported Platforms Windows 10 / 11 (64-bit), macOS 12+, Linux (Ubuntu, Debian, Fedora)
Memory Footprint Approximately 12MB - 15MB RAM
Network Protocols IPv4 / IPv6, TCP/IP Stack, UDP Socket Telemetry
